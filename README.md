# Autohuolto Tuomainen — nettisivut

Uudet sivut yritykselle Autohuolto Tuomainen (Mikkeli). Staattinen HTML/CSS/JS, ei palvelinriippuvuuksia.

## Esikatselu koneella

Avaa `index.html` selaimessa, tai käynnistä paikallinen palvelin:

```bash
npx --yes serve .
```

## Julkaisu

Lataa nämä tiedostot webhotellin juureen (FTP tai tiedostonhallinta), vanhojen sivujen tilalle:

- `index.html`
- `hinnasto.html`
- `renkaat.html`
- `ohjelmointi.html`
- `yhteystiedot.html`
- `404.html`
- `robots.txt`
- `sitemap.xml`
- `.htaccess` (Apache-palvelimille)
- kansiot `css/`, `js/` ja `img/`

Vanhat tiedostot (`index.html`, `hinnasto.html`, `renkaat.html`, `ohjelmointi.html`, `style2.css`) voi korvata.

## Sisältö

Yhteystiedot, hinnat, aukioloajat ja palvelut on otettu nykyiseltä sivustolta ja julkisista lähteistä. Hinnastossa on merkintä varmistaa ajantasainen hinta puhelimitse.
